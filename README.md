# 卡之洞預購系統｜HTML 互動原型

## 集中對帳

管理端 → 訂單管理 →「匯款集中對帳」。可跨訂單搜尋、篩選匯款狀態、查看憑證、逐筆退回，或勾選多筆並確認入帳。每筆款項分別保留訂單紀錄與通知預覽。仍為本機示範，未串接銀行或共用資料庫。

## 首次部署紀錄

以下為首次部署時的指示；後續集中對帳功能由使用者另行要求新增。

### 如何交給 Codex

1. 解壓縮 ZIP。
2. 在電腦上的 Codex 開啟 `cardscave-preorder-preview` 資料夾。
3. 貼上以下指令：

```text
請先閱讀 CODEX_DEPLOY_PROMPT.md，將這個資料夾的原型上傳到我的 GitHub 帳號 CyanYu5，使用獨立專案 cardscave-preorder-preview。不要修改 HTML，不要碰 farmhouse-preview。請實際檢查 GitHub 登入、寫入權限與目標專案狀態後執行；只有帳號授權、公開可見性或覆寫衝突等必要事項才向我確認。若可安全啟用 GitHub Pages，請一起處理，完成後驗證提交與網頁，回報實際可用的連結。
```

## 原型界線

這份檔案是預購系統的用戶端／管理端互動原型，不是已串接正式服務的會員系統。

- 不應填入真實會員個資、匯款證明、密碼或金鑰。
- 前端管理介面僅供展示，不代表具備正式管理員身分驗證。
- 沒有真的寄送 Email、LINE 訊息、收款、退款或建立物流單。
- 本機瀏覽器的示範資料不等於共用資料庫，不同裝置不會因此同步訂單。
- 商品圖片使用外部來源；離線或來源失效可能無法顯示。
- 活動日期與付款規則是原型案例資料／待確認規則，不代表目前仍可收單或已完成法律與營運審查。

可先用桌面瀏覽器開啟 `index.html` 查看原型。GitHub Pages 的發布不會把原型轉成正式訂購服務。
